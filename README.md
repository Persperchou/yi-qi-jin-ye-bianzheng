# 一气津液辨证框架（v3.1）

> 一个从能量-物质转化"画面"出发的中医临床辨证思维模型——不必学完五行脏腑八纲六经再回头，直接抵达病机。

---

## 这是什么

一气津液辨证是一套**临床可操作**的辨证与用药法度框架。它以「一口锅、两把火、一锅水、一份油、一道墙」的物理图像为认知起点，把人体抽象为**能量—物质—空间—时间**四个层面的动态系统，目标是：

1. **解释过去**——统一解释经典中医理论与经方方证
2. **预判未来**——临床辨证开方不止于叙事性解释，而能预测病势走向、换方时机与态间转换
3. **可校准**——内置经方四变量投射表作为校准码，任何新维度加入必须回测，防止框架对经典方剂产生误判

## 理论根基

| 元素 | 物理图像 | 对应 |
|:---|:---|:---|
| **真阳**（灶底火） | 先天火种 | 命门之火 |
| **真气**（灶面火） | 后天转化 | 脾胃化生之气（量 + 通滞） |
| **精**（灯油） | 战略储备 | 肾精 |
| **津液**（水+精微） | 灌溉系统 | 全身流体（七态） |
| 锅壁 / 旋转门 / 锅内管道 | 空间轴 | 表 / 枢（少阳）/ 里 |

学术脉络：本能论（郭生白）的自主排异与自组织、圆运动（彭子益）的气机升降，融汇郑钦安、胡希恕、柯琴、倪海厦、张锡纯、李可、刘渡舟诸家之学。

## 框架结构（v3.1）

```
［空间轴］横：表 ── 枢 ── 里    纵：上焦 ── 中焦 ── 下焦
［通滞轴］真气：郁→疏 / 逆→降 / 滞→行
［病势轴］静态浊毒 vs 动态炎毒 —— 正反馈回路检测（急/慢两级警报）
［核心引擎］真阳 · 真气 · 精 · 津液（四变量，恒定不变）
```

- **四变量 + 十三态速查表**（含 v3.1 新增 #13 血热耗气态）
- **药法执行层**：能量层 / 津液层（七态+热力学标签）/ 清热保津 / 气机 / 通腑攻下
- **十五律核心铁律**
- **经方校准码**：13+ 核心经方的四变量投射表
- **辨证五步法**：空间定位 → 四变量遍历 → 病势判定（两级警报）→ 态定位 → 方药落地
- **医案管理跟踪体系**：建档模板、归档规则、季度态转换轨迹看板

## 使用方式

技能文件遵循标准 SKILL.md 格式（frontmatter 含 name/description/触发词），放入技能目录即可被调用。触发词包括：一气津液、津液辨证、经方辨证、血热发斑、舌红苔白、凉血透热等。

临床分析流程：先结论后推演——空间定位 → 四变量 → 病势 → 态 → 药简力专的方药。

## 模型边界

- 框架是分类+监测工具，不是确定性预测工具；态间转换规律为临床观察总结
- 空间定位依赖四诊，亚临床期需生化指标补充
- 慢性炎性自催化的二级警报阈值仍为经验性，待医案积累量化
- 外伤、大出血、急性中毒等不完全适用；框架定位于内伤+外感病的能量-物质代谢分析，不替代现代医学评估
